🛡️ reposec

Runs entirely in your browser — your code is never uploaded.
No scan yet. Open a GitHub repository and click “Scan for secrets”.
Stored locally, sent only to api.github.com to list and read files. A token is needed for private repos and for anything large enough to hit the anonymous rate limit.
Unsafe-code analysis (bandit, eslint-plugin-security) needs a local process. Run reposec scan . for all three detectors, git history, and CI gating.
